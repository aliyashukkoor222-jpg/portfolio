# Aliya's Portfolio

Hi, I'm Aliya. I'm a fourth-year B.Tech Computer Science Engineering student, graduating in 2027. This is my portfolio, where I keep the projects I'm working on and the things I'm learning. I'm most interested in AI, software development, and cybersecurity.

I built the site with plain HTML, CSS, and JavaScript. I skipped frameworks on purpose because I wanted to get comfortable with the basics first. It's still a work in progress, and I update it as I learn.

## What's on the site
- A bit about me and how I like to work
- The skills I'm building right now: Python, Java, MySQL, AI, Git and GitHub, and cybersecurity
- Two project ideas I'm developing
- Links to my LinkedIn, GitHub, and email

## Projects
**OfflineMind** is an idea for an AI assistant that keeps working when the internet doesn't. Plenty of tools become useless the moment you're offline, and I want to see if I can build something that doesn't.

**Interest-Based Connections** is a website concept for finding people through shared interests and goals instead of dating-style matching. I kept thinking about how hard it is to meet people who are into the same things, especially outside the usual apps.

Both are at the planning stage. As they become real, I'll add demos, screenshots, and links to the code.

## Running it on your computer
Clone the repo or download it, then open `index.html` in a browser. There's nothing to install. If you'd rather work on it, open the folder in VS Code and use the Live Server extension.

## Files
- `index.html` is the page content.
- `style.css` is all of the styling.
- `script.js` handles the mobile menu, scroll behavior, and small details.
- `favicon.svg` is the "A." icon in the browser tab.
- `README.md` is this file.

## Hosting
The site is meant to run on GitHub Pages. In the repo, go to Settings, then Pages, choose Deploy from a branch, and select `main` and `/ (root)`.
